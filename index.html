WorldLeague Benchmark

Physical goals and task demands

Robots explore scenes to gather evidence in WorldSeek, rearrange objects in WorldShape, and adapt to changes in WorldShift.

WorldSeek

  • Where the robot goes determines what it can reach and what it can see.
  • In a WorldSeek task, the robot may need to
    • plan routes to destinations or viewpoints
    • gather evidence to identify a target
22 tasks · Navigation & Grounding

WorldShape

  • How the robot reshapes its surroundings determines what it can build and what will hold after it lets go.
  • In a WorldShape task, the robot may need to
    • arrange objects in a required spatial relation
    • reason about motion, contact, and support
24 tasks · Geometry & Physics

WorldShift

  • What the robot sees and remembers determines which changes it can recognize and how it can adapt its plans.
  • In a WorldShift task, the robot may need to
    • interpret changes or requests using earlier observations
    • maintain or restore required conditions
14 tasks · Memory & Constraints

Scoring physical goals

For each task, the robot’s trajectory shows which goal requirements it satisfies and whether it completes the task. We compute the Interactive Score as the mean credit across goal items, scaled to 100. Physical success requires satisfying the full goal and all task constraints.

The interface

WorldHarness

Decision-preserving action abstraction

WorldHarness implements this abstraction on R1 by adapting Show-Harness. Given the public goal, camera observations, and retained history, the vision-language model (VLM) selects a base, arm, trunk, or gripper command. The controller executes the motion and returns feedback, which the VLM can use to revise its next command.

Vision-language-action models (VLAs) and world-action models (WAMs) use their native controls. All three model families share the task goals, constraints, and physical scoring rules.

Evaluate your model

Start with the task catalogue on CPU. For an R1 episode, use the OmniGibson simulator environment with the licensed BEHAVIOR assets.

Get the benchmark

git clone https://github.com/xyangzhou/WorldLeague
cd WorldLeague
python -m pip install -e .
git clone https://huggingface.co/datasets/xyangzhou/WorldLeague benchmark
worldleague tasks

Run a VLM episode

worldleague eval T04 --config luna-medium \
  --gpu 0 --output runs/luna/T04

Install the sibling WorldHarness checkout and set the preset’s API key first. Simulator setup
